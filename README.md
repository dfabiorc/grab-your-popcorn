# Grab Your Popcorn

Discover what to watch next: the latest releases, with cast, crew, trailers and
reviews from [TMDB](https://www.themoviedb.org/). A static React app deployed to
GitHub Pages.

> Work in progress. Full documentation lands with the first release.

## Run locally

```bash
npm install
cp .env.example .env.local   # then add your TMDB v3 API key
npm run dev                  # http://localhost:5180/grab-your-popcorn/
```

This product uses TMDB and the TMDB APIs but is not endorsed, certified, or
otherwise approved by TMDB.
